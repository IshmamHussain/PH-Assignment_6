# FitLog - Train With Intent. Log Every Set.

FitLog is a dark, no-nonsense gym companion designed to help you pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies Used
- Next.js (App Router)
- React
- Tailwind CSS v4
- Zustand (State Management + LocalStorage Persistence)
- React Hot Toast (Notifications)
- Lucide React (Icons)

## Key Features
1. **Browse 12+ Exercises**: A comprehensive library covering every major muscle group, sorted by duration, calories, or rating.
2. **Detailed Workout Views**: Individual detail pages for each workout with equipment, sets, reps, and step-by-step instructions.
3. **Plan Your Day**: Add up to 5 workouts to "Today's Plan" and view aggregate metrics like total duration and calories.
4. **Save for Later**: Easily bookmark exercises into a dedicated "Saved" tab to build future routines.
5. **Mark as Done**: Check off completed lifts in your plan to stay on track.
6. **Local Storage Persistence**: Your plan and saved workouts survive page reloads automatically.
